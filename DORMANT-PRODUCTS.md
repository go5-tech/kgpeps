## Re-enabling a product

To re-enable a dormant product, follow the steps documented when it was dormanted (check git history for the dormant commit message referencing this file).

General checklist:
1. Set `"active": true` in `products.json`
2. Add nav links back to all pages
3. Add YMAL cards on related product pages
4. Add back category page card + "View Product" button
5. Add SEO list link on homepage and `/buy-peptides-india/`
6. Update the product page display name if it was renamed
